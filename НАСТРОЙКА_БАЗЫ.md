# Подключение Avito Türk к новой базе Supabase

1. supabase.com → New project (регион ближе к Турции, например Frankfurt). Запомните пароль БД.
2. SQL Editor → New query → вставьте весь файл `supabase_schema.sql` → Run. Должно пройти без ошибок.
3. Settings → API: скопируйте **Project URL** и **anon public key** в `supabase-config.js`.
   (service_role key никуда не вставляйте!)
4. Задеплойте файлы на Vercel (или любой хостинг).
5. Откройте сайт, зарегистрируйтесь — это будет ваш аккаунт.
6. Сделайте себя главным администратором: SQL Editor →
   `update public.users set role = 'SUPERUSER' where lower(username) = lower('ВАШ_ЛОГИН');`
   затем выйдите и войдите снова.
7. Storage → убедитесь, что bucket `listings` существует и публичный (схема создаёт его сама).
8. Authentication → Providers: Email можно отключить — приложение использует собственный вход.

Ограничения: «Импорт бэкапа» пользователей и переводы/оплата AvitoCash внутри платформы отключены в базе (безопасность).
